# Louisiana Legislator Email Page

This is a static webpage designed for GitHub Pages.

## Publish with GitHub Pages
1. Create a GitHub account if you do not already have one.
2. Create a new public repository named `louisiana-legislator-email`.
3. Upload `index.html` to the repository.
4. Open Settings -> Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select the `main` branch and `/ (root)`, then Save.
7. GitHub will provide the public website address.

The page uses mailto links. A visitor must approve/send the message through their own email program.

Recipient lists should be periodically checked against the official Louisiana House and Senate directories because legislative email addresses can change.
